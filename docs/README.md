# Documentation

- [Sprint 1: sole-trader journey](sprint-1.md): scope, sources and the order of steps.
- Install: download `mitos-checklist.zip` from the latest release, upload in Plugins → Add New, activate.
- Settings → Mitos Checklist: add procedure codes (the number in `https://id.mitos.gov.gr/<code>`), "Save and sync now".
- Shortcodes: `[mitos_checklist]` searchable list, `[mitos_checklist id="…"]` one procedure, `[mitos_journey id="freelancer"]` guided journey.
- Developers: filters `mitoschk_journeys`, `mitoschk_document_sources`, `mitoschk_language` (`en` for English).
